JailMonkey is a React Native library that lets you detect whether a device has been jailbroken (iOS) or rooted (Android), and whether GPS location is being faked. With a simple, consistent API across both platforms, you can make informed decisions about what features to enable — or restrict — based on device trustworthiness.

## Why use JailMonkey?

Some apps need to protect data integrity — users faking GPS coordinates to cheat, or running modified builds to bypass restrictions. JailMonkey gives you a reliable signal to act on.

<Steps>
  <Step title="Install the package">
    Add JailMonkey to your project:
    ```bash
    npm install jail-monkey
    ```
    For iOS, run `pod install` in your `ios/` directory.
  </Step>
  <Step title="Import and check">
    Import JailMonkey and call any detection method:
    ```typescript
    import JailMonkey from 'jail-monkey';

    if (JailMonkey.isJailBroken()) {
      // Restrict access or show a warning
    }
    ```
  </Step>
  <Step title="Handle the result">
    Use the return value to gate features, log security events, or present a warning to the user.
  </Step>
</Steps>

## What JailMonkey detects

<CardGroup cols={2}>
  <Card title="Jailbreak / Root" icon="shield-xmark">
    Checks filesystem paths, URL schemes, symlinks, dylibs, and sandbox violations on iOS. Uses RootBeer and native checks on Android.
  </Card>
  <Card title="Mock locations" icon="location-crosshairs">
    Detects GPS spoofing apps and developer-mode mock providers on both iOS (via CLLocation) and Android.
  </Card>
  <Card title="Hook detection" icon="bug">
    Identifies suspicious hooking frameworks installed on Android devices that could intercept app logic.
  </Card>
  <Card title="Debug & ADB" icon="terminal">
    Detects if the app is running in debug mode or if Android Debug Bridge is enabled on the device.
  </Card>
</CardGroup>

<Note>
  Since emulators are typically rooted by default, you may want to bypass JailMonkey checks during development. See [Emulator bypass](/guides/emulator-bypass) for guidance.
</Note>
